# Haunted House - Three.js

**Live:** https://haunted-house.micheletornello.com

An interactive 3D haunted house scene built with Three.js, packaged with webpack.

## Build

```bash
npm install
npm run build   # webpack production config -> dist/
```

Serve locally for development:

```bash
npm run dev     # webpack dev server
```

The production build is a static bundle emitted to `dist/` and deployed on Vercel.
